# Hello World

Welcome to the whis blog! We're excited to launch this space where we'll share updates, tutorials, and insights about voice-to-text on Linux.

## What is whis?

whis is a voice-to-text tool for Linux that lets you record anywhere, transcribe fast, and paste instantly. It comes in three flavors:

- **CLI**: For terminal workflows — run `whis`, speak, done
- **Desktop**: System tray app with global hotkey support
- **Mobile**: Android app for voice-to-text on the go
